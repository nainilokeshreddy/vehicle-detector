# Dataset Directory

This directory stores datasets and sample test media for the Autonomous Vehicle Perception System.

## Structure
- `images/`: Contains sample or test road images (e.g., dashboard camera images, vehicle views, traffic scenes).
- `labels/`: Contains ground truth annotations or labels (e.g., YOLO format or bounding box metadata) if fine-tuning or evaluation is conducted.

> **Note:** Actual dataset files will be populated during the data collection step.
